A- Z Series → Divide & Conquer

Hope You are safe and eagerly waiting to learn the divide & conquer approach.

If you can break a large problem into smaller problems and these subproblems can be solved and you can obtain the solution for each subproblem then you can combine those solutions to get the solution for the large problem. 

Divide → You will divide the problem into small subProblems. [P = sum(SPi)]
& → You will find a solution for the subProblem [SSi = solution(SPi)]
Conquer → You will combine solutions that are used to solve the subProblems to get the solution for the exact problem. [S = sum(SSi)]


How to Identify a problem that can be solved with this divide and conquer strategy?

  • The subProblem should have the same behaviour as the main problem has. The subproblem should be a clone of the problem with a small size. 
     → If a problem is to search an element in the list then the subproblem also should search the element in the list. 
  • The problem is recursively in nature
  • When you break a problem into subProblem then you should have a way to combine their solutions to the main problem. 

Algorithm For Divide & Conquer

divideAndConquer(p){
   if(small(p)){
        s = solution(p)
   }
   divide p into p1,p2,p3....pn
   apply(divideAndConquer(p1),apply(divideAndConquer(p2).....
   combine(divideAndConquer(p1),divideAndConquer(p2)..)
}

Sample Problems

  1. Binary Search (we can split the array still it is the same problem to search an element on each array)
  2. Find Max & Min ( we can split the array still it is the same problem to find the max/min on each array)
  3. Merge sort 
  4. Quicksort

Above problems are well known for divide & conquer approach
