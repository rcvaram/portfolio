Avoid FTP/ FTPS

The difference between FTP & FTPS is Security layer is added on top of FTP. Both use two ports. Two ports are used for the command channel & data channel. 

FTPs it uses SSL/TLS to encrypt the data being transferred. In addition, SFTP provides a number of other security features such as the ability to authenticate the users using public-key cryptography and to use the secure file permissions. SFTP is generally considered to be more secure than FTP / FTPS. 

Read a File From SFTP without downloading the file to Local

SftpRemoteFileTemplate

We are going to use the SftpRemoteFileTemplate to read the file from remote server.

We use the SftpRemoteFileTemplate to connect to the Sftp Server and read the file the specified place. This way We are not going to download the file to our local system. We just read out from the remote server.


Add your dependency in your Gradle file

implementation group:'org.springframework.integration', name:'spring-integration-sftp'

SftpRemoteFileTemplate Bean Creation


import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.integration.sftp.session.DefaultSftpSessionFactory;
import org.springframework.integration.sftp.session.SftpRemoteFileTemplate;

import java.time.Duration;

@Configuration
public class SftpConfig {
    
    @Value("${sftp.url}")
    private String url;

    @Value("${sftp.user}")
    private String userName;

    @Value("${sftp.password}")
    private String password;

    @Value("${sftp.port}")
    private int port;

    
    @Value("${sftp.connect.timeout.millis}")
    private int connectionTimeOutMillis;

    @Value("${sftp.session.connect.timeout.millis}")
    private int sessionConnectionTimeOutMillis;

    @Bean
    public DefaultSftpSessionFactory sftpSessionFactory() {
        DefaultSftpSessionFactory sftpSessionFactory = new DefaultSftpSessionFactory();
        sftpSessionFactory.setHost(url);
        sftpSessionFactory.setPort(port);
        sftpSessionFactory.setUser(userName);
        sftpSessionFactory.setPassword(password);
        sftpSessionFactory.setTimeout(sessionConnectionTimeOutMillis);
        sftpSessionFactory.setChannelConnectTimeout(Duration.ofMillis(connectionTimeOutMillis));
        return sftpSessionFactory;
    }

    @Bean
    public SftpRemoteFileTemplate sftpTemplate() {
        SftpRemoteFileTemplate template = new SftpRemoteFileTemplate(sftpSessionFactory());
        return template;
    }
}

  @Autowired

    }
  }
}
