Image Scaling Depth Analysis

We will look at how to scale the image. In most computer vision tasks, we need to change the image size. Sometimes we capture images in high resolution which means a very large number of pixels. So that, we can get even the finer details of the image. when we try to process the image like searching some object at that time, we need more system memory and processing power to scan a very large space. At that time, we need to scale down the image. 

How these operations can be done image

 We need to understand some concepts to understand the scaling of an image

pixel Connectivity

We know that images are made with a lot of pixels. So some of theses pixels are marked as the boundary of an object. These boundaries are a vital part in computer vision since they separate the Region of interest (ROI) from the image.

So How can we define these boundaries? These boundaries can be defined by a connected set of pixels. 

Ok, How can we define the two pixels to be connected to each other? If two pixels are adjacent to each other in some sense they satisfy some similarity in the gray level.

Similarity criteria examples

 * Gradient
 * Color with a particular range


How can be defined adjacency?

Let V be the set of gray-level values used to define connectivity. For example, V={1} or V = {51, 52, …, 60}

  • 4-connectivity → Two pixels p and q with values from V are 4-connected if q is in the set N4(p)
  • 8-connectivity → Two pixels p and q with values from V are 8-connected if q is in the set N8(p)

Adjacent Pixels

A pixel p is adjacent to pixel q if they are connected. We may define 4- or 8- adjacency depending on the type of connectivity. 

We can also define adjacent image regions. Two image subsets S1 and S2 are adjacent if some pixel in S1 is adjacent to some pixel in S2. 

Path

A path from pixel p with coordinates (x,y) to pixel q with coordinates (s,t) is a sequence of distinct pixels with coordinates (xo,yo), (x1,y1) ….. (xn,yn).

the starting point → (x0,yo)

ending point → (xn,yn)

We define a continuous path from point A(xo,yo) where pixel value p to point B (xn, yn) where pixel value q there exists a set of pixels each (xi, yi) pixel is adjacent to (xi-1, yi-1).

 Similarly, we can define 4- or 8- path depending on the type of adjacency specified. 

If p and q are pixels of an image subset S then p is connected q in S if there is a path from p to q consisting entirely of pixels in S

Local Neighborhoods

Sample windows selecting different neighbourhoods of pixel P. Used when operations relating to a group of adjacent pixels are applied.

Example of neighbourhoods

  • 4 neighbourhoods (top, bottom, left and right)
  • 8 neighbourhoods ( 4 + 4 diagonal pixels)
  • 12 neighbourhoods ( 8 + 4 neighbourhoods next layer)


Distance measures

Given pixels p, q and r, with coordinates (p1, p2), (q1, q2) and (r1, r2) respectively, we call D a distance function or metric if

  1. D(p,q) ≥ 0 (D(p,q) = 0 iff p= q)
  2. D(p,q) = D(q,p)
  3. D(p,r) ≤ D(p,q) + D(q,r)


Some distance measures examples

Euclidean distance {D(p,q)} = |(p1-q1)^2 + (p2-q2)^2|0.5
D4 distance {D(p,q)} = |p1-q1| +|p2-q2|
D8 distance {D(p,q)} = max(|p1-q1|, |p2-q2|)
