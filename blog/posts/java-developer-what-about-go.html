Java Developer WHAT ABOUT GO

Go is an open-source programming language originally from Google that makes it easy to build simple, reliable, and efficient software. Above is the statement where you can find the official site of the Go.

Google says that it can use to scale. 

Go is not a scripting language like ruby or python.

Why Go for Java developers?

Go is a better choice than java in some situations such as in fracture components. Go projects can be integrated with existing Go projects.
