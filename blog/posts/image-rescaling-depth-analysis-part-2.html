Image Rescaling Depth Analysis Part 2

We will look at how to scale the image. In most computer vision tasks, we need to change the image size. Sometimes we capture images in high resolution which means a very large number of pixels. So that, we can get even the finer details of the image. when we try to process the image like searching some object at that time, we need more system memory and processing power to scan a very large space. At that time, we need to scale down the image.

How these operations can be done image

We need to understand some concepts to understand the scaling of an image

Properties of the image are the size of the dot, how many dots you get and the shape of the dots.

Resolution

How many dots/pixels in unit length or density of dots can be defined as resolution. When we say our camera is 30 Megapixels. It is not resolution and it is the size of the image.

Image Size

How many dots/pixels are in the image. Its count of dots/pixels.

Aspect Ratio = Number of Rows/Number of Columns

Normally when we say 4:3 aspect ration and our image 40 cm in width we can say 30 cm in height. Also, we can say 40 pixels in width and 30 pixels in height if pixels per cm is 1. (Resolution is 1 DPcm)


Pixel Aspect Ratio = exact shape of the image

Most of the time, we get a 1:1 pixel aspect ratio. Sometimes, we may have 1.3:1 pixel aspect ratio also.

Based on the above definitions, we can come to the physical width and physical height of an image

Physical Height and Physical width are functions of the resolution, the number of columns/ rows and the pixel aspect ratio.

Physical Height → f(res, col, pixel aspect ratio)

Physical Width → f(res, row, pixel aspect ratio)

If 30 pixels in row and 40 pixels in column and resolution is 2 dpi(2 dots per inch or 2 pixels per inch) and pixel aspect ratio is 1:1 then 

height = 30pixels/(2dpi*1) = 15 inchs

width = 40/(2dpi*1) = 20 inchs


Let's focus on Resampling

Change in any of these parameters will result image size and geometry to change.

Change number and value of pixels requiring new values for pixels.

 * To add as new pixels when we do up-sampling
 * To replace existing pixels/discard pixels when we do down-sampling

But When we do resampling, the re-sampled pixels must do the following criteria

* Preserve Image feature including fine details
* Reduce Noise
* Not introduce any artifacts


These conditions are satisfied then we can say this is ideal scaling but it is not possible in practical situations.

Scaling By Factor of 2

It can be made the image larger by a factor of 2 or smaller by a factor of 2. It’s considered one side by a factor of 2.

The easiest way is replicating each row/column to enlarge the image.

If you want to reduce the image, you can discard every other row/column.

What are the issues that can be faced here?

  • Finer image details get lost when downscaling (specially one-pixel wide features)
  • Checker-board effect when upscaling
  • Aliasing effect

Why we miss finer details here because the details are in 1 pixel so how can we avoid is just make blur the image when we blur the image, features will be spread to neighbours. so what we need to do before downscale, we need to pass image to the low pass filters.

Nearest Neighbour method scaling

Replace each new pixel with the one having the closest distance to its N4(p) neighbours. Any distance matric can be used to find the closest distance however some schemes will reduce computational demand. This method preserves most of the finer details but the checker-board effect may result. The aliasing effect will be a more likely problem here.


Interpolation in Rescaling image

We can do bilinear interpolation and cubic interpolation.


Aliasing Effect

The aliasing effect is more prominent with high-frequency components where finer details are present.

According to Nyquist theory sampling must be at least twice the highest frequency to capture all details.

Some degree of blurring can reduce the effect of aliasing but at the expense of loosing high-frequency components (affects less in sub-sampling)
