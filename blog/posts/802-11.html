We have some antennas that are sending and receiving data. There is a bridging device that bridges into an ethernet network. There is a RJ45 port that can be used to pug an ether network. This one has an IP address to speaks via radio waves to other devices. 

The home router has some switch ports and internet connection. This Home router is a wireless access point, switch and a router. This is a kind of device that does all kind of stuff all wrapped in one. when you have multiple RJ45 then that is not a WAP that is Router.

802.11’s basic concept is a service set identifier or an SSID. In order to make the radio wave work you go into these devices one way or another and you set an SSID. This SSID is a term that this device will normally broadcast out and a client can be logged into that. There are two ways. The first way to go about it and by far the most common way is what we call infrastructure mode which means you are using a wireless access point.

 When you are using a wireless access point then it means you are in infrastructure mode. ther is another way which is called as Ad hoc mode. Ad-hoc networks don’t require a centralized access point. Instead, devices on the wireless network connection directly to each other. If you set up the two laptops in ad-hoc wireless mode, they’d connect directly to each other without the need for a centralized access point. 

Infrastructure mode is ideal if you’re setting up a more permanent network. Wireless routers that function as access points generally have higher-power wireless radios and antennas so they can cover a wider area. If you’re using a laptop to set up a wireless network, you’ll be limited by the power of the laptop’s wireless radio, which won’t be as strong as a router’s.
