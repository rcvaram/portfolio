The Code to Guess🎲

What does this print 🤔?

Think about it for a second ✍️
— — — — — — — — — — — — — — —
Is it 15 then 15?
Or
is it 15 then 96?

Ready? Let’s find out together!

Step 1: What’s in the Box📦?

Inside Box, we have:

  • final int number→ This is a number that can’t change once it’s set. The final lock it 🔒.
  • static Box box = new Box(15) → This makes a box with a Box inside📥. That Box has number = 15. The static means it’s shared — like one toy everyone can use.
So, at first,
the box has a Box with the number = 15. Easy so far😄? Let’s go on.

Step 2: First Look 👀

The first line says: System.out.println(Box.box.number);

We look in the box. It’s got a Box with the number = 15. So, it prints:15

No tricks yet. It’s like opening a box and seeing 15.

Step 3: The Switch🔄

Now this happens: Box.box = new Box(96);

What’s going on? We make a new Box with number = 96. The final locks it at 96 🔒. 
Then, we put this new Box in the box 📤. The old Box with 15 goes away 👋. The box now has a new one.

Here’s the trick: final locks the number, but not the box. The box can hold something new anytime!

Step 4: Second Look 👀

Now we check again:System.out.println(Box.box.number);

What’s in the box? It’s the new Box with the number = 96. So, it prints: 96

The Answer

15
96

Did you guess right? If yes, great job🙌! If not, it’s okay — this fools lots of people including me😅.

The final word only stops the number from changing. The box can still swap what’s inside.

you’ve seen the final maybe for constants.

This shows it’s not magic — it only locks one part. In real code, this matters when you share things or keep them safe.

Why This Tricks You

I put static and final in the same code, and that can confuse you! 
final locks the number inside each Box — so 15 can’t change in the first Box, and 96 can’t change in the second. 
But static box?
 It’s not locked! static just means it’s shared, and we can still swap what’s in it. You might think the final keep everything the same because you see it next to static, but no — only the number is safe.
The box can change, and that’s the trick!
