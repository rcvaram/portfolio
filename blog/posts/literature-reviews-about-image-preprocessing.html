An OCR system for handheld devices

An OCR system for handheld devices is proposed in this paper with the below architecture. This system has many challenges, these kind of images very often suffer from skew and perspective distortion. More than that, uneven illumination and the insufficient illumination are the common challnges

As they mentioned, the first step is extracting the text.

The input image is divided into m blocks then the blocks are categorized as background block or information block using intensity variation.

Skew correction happens after the text extraction since the captured images might not be uniformly skewed because of perspective distortion. 

After the skew correction, the image is sent to binarization.

 An improved version of Bernsen’s binarization technique which is proposed in this paper is used for binarization. 

Segmentation happens after the binarization.

 97.48% segmentation accuracy is achieved for 3 MP images. This accuracy is achieved when the image font is a normal regular font, not italic or cursive text. 

Recognition happens after the segmentation. They considered 73 letters which are used frequently. With the experiment result, they reduced the set to 62 classes. The maximum accuracy has been obtained with 62 classes. 

This system can be implemented with a post-processing step then the accuracy may be increased and that will be their future work.

Binarization methods

Binarization is used commonly in image preprocessing since it might impact ocr results[7]. 

The two approaches are used commonly in binarization; global binarization(Otsu) and local adaptive binarization. 

Local adaptive binarization is not prefered for normal images. Otsu, NiBlack, Sauvola, Wolf, Nick and Batainesh are the methods used in binarization.

 This paper illustrates that the local adaptive binarization methods give better results in non-uniform intensities, uneven illumination, or shadow-degraded cases.

Otsu binarization works well in normal images since it divides the foreground from the background very effectively using the histogram anlysis.

Efficient and Robust Specular Highlight Removal[10]

Specular highlights or glare make difficulties for compute vision tasks like binarization, segmentation and more.

They observed a behaviour of an image that the image smoothness is proportional to the maximum friction of diffuse colour components of an image.

So that, specular pixels can be treated as noise. It can be removed from an image in a denoising fashion.

This specular highlight removal can be done in two ways one is based on using multiple images and other one is using a single image. The most challenging task is using single image to remove specular highlights. 

Colour segmentation, analysing the distribution of image colour within a colour space are the techniques used in single image specular highlight removal.

Authouthrs imporved or modified an existing idea of Tan & IKUSHI which is relaxing the general pixels to chromaticity pixels with adding their observation.

IN THEIR METHOD, specular pixel colour is got from a nonlinear function of the original color of the pixel and the maximum fraction of the diffuse color component(maximum diffuse chromaticity). This chromaticity pixel value is estimated by directly applying a low-pass filter to the maximum color component image.

This gives better results than earlier one of the tan & IKUSHI.

An overview of an tessract engine

Tessract was initially started by as PHd project of hp and is maintained by google now. Tesseract Architecture can be looked as below.

First one is adaptive thresholding, Otsu binarization method is used to binarize the input image. the binarization happens in small divisions of an image.

IN page out analysis, the image was divided into text and non-text area. This is based on a 7 steps process which is taps-stop approach of an document iamge.

A novel algorithm is used to finding rows of text in a page. Using a quadratic spline by a least square fit, the baselines are fitted. Definite spaces and fuzzy spaces are used to divide the text.

Tesseract uses both static classifier and adaptive classifier in classification. A static classifier is used to recognise the text in first pass. adaptive classifier which is trained by the recognised words is used to recognise the unrecognised words in second pass
