React — Day 1

React makes building complex interactive & reactive user interfaces simpler.

React is all about “Components”

Component

All user interfaces in the end are made up of components. 

Why?

  • Reusability → Don’t Repeat yourself
  • Separation of Concerns → Don't do too many things in one & the same place.

How?

User interfaces include HTML, CSS and JS. React allows you to create reusable & reactive components of HTML & JavaScript & CSS. It uses a declarative approach. 

React code is written in a declarative way

Define the desired target state & let React figure out the actual JS DOM instructions. 

Create React APP

Bunch of configuration files, a friendly development environment, with a web server. It simplifies the development process. 

npx create-react-app react-expenses-tracker-v1

It will set up the react project for you.

npm start

It will start the development server.

 Scratch Project

package.json

It holds all the dependencies of the project. 

src

Actual source code you are going to work.

index.js

This file will be executed when you start the server. This is not regular JS code. This code will be synthetic sugar and it will work since it will be transformed into actual code by the react and this makes the dev life easier. 

import ReactDOM from 'react-dom/client';
import './index.css';
import App from './App';
const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<App />);

We are importing ReactDOM from react-dom. Single HTML file It consists a div with id called root. This DIV will be used to attach the user interface that is created by react.

  1. We are creating a root with that particular root. the main place to render the app.
  2. We are calling the render method to show what we selected here.

Basically, react will replace the HTML div with the <App /> 

What is App?

function App(){
   return(
     <div> 
        <h2> Let's get started </h2>
     </div>
    );
}
