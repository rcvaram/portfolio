Classes and Objects

When you are using a computer, that computer is identified as an object in the real world. How your computer is identified as a computer? It’s all about the design of that particular object is identified makes you think of a computer. This design can be illustrated with a blueprint. based on the blueprint, the manufacturer will create the computer.

This blueprint is called as class in programming language

What we derived from the blueprint/template, we call them as the object.

You know, the computer has some attributes like colour, size, shape and extra. Also, we know, computers can do some works these works are called methods/functions of that class. 

Basically, The class is constructed with attributes and methods.

How Dart handles this

class Computer{ 
 //We will set all the instance attributes
 String model;
 int size;
 String color;
 bool active;
 //We can also define methods using following syntax
 void turnOn(){
  active = true;
  print("I am starting.....);
}
 void shutDown(){
   active = false;
   print("I have been turn offed....!!!");
}
void restart(){
   print("I am restarting.....");
 }
}
//Initalize the computer class instance inside the main function
main(){ 
  var com = new Computer();
  //We are setting attributes 
  com.model = "HP Elitebook x360";
  com.size = 16;
  com.color = "Silver";
  // We can call the functions/methods of an bject
  com.turnOn();
  print(com.active);
  com.shutdown();
}

The above code shows you that we can use the dot(.) operator to set and get the attributes of the class.

The construction of an object when the object is initialized is the nice way to create an object.

What states/attributes would have an object when it is created is defined in constructor.

What is this keyword in dart?

Inheritance

You may have the same characteristics that your parent had like colour, eye, height and more. Here, You inherit those characteristics from your parent. 


class Thing{
 String colour;
 int age;
 void showColor(){
   print(this.colour);
} 
}
//This computer has all attributes and methods which are in Thing class
class Computer  extends Thing{
 int size;
 }
main(){
var dell = new Computer();
dell.colour = "BLACK";
dell.showColor(); 
dell.size =12;
var thing = new Thing();
thing.size =13// WIll be ERROR since thing is not have size attribute
}

child class can may have own characterists . We need to veride some methods since all the methods will not be the same for child and parent.

class Thing{
 String colour;

   print(this.colour);

 void start(){
  print("I am starting");

//This computer has all attributes and methods which are in Thing class

 int size;
 @override

  print("I am turning on");
 }
