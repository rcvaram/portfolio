Insertion Anomaly

To insert redundant data for every new row (of Student data in our case) is a data
insertion problem or anomaly.

Deletion Anomaly

Loss of a related dataset when some other dataset is deleted.

Update Anomaly

1st Normal Form

This the stpe one of normlaization process. 

  • Scalable Table design which can be easily extended.
  •  If your table is not even in 1st Normal Form, its considered poor DB design.

Every Table in your Database should at least follow the 1st Normal Form, always.
or Stop using Database!

How to achieve 1st Normal Form?
There are 3 basic rules that a table should follow to be in 1st Normal Form.

Rule 1 — Atomicity

  • Each Column should contain atomic values. Entries like X, Y and W, X violate this rule.

Rule 2 — Column Data in One Type

  • A Column should contain values that are of the same type. Do not inter-mix different types of values in any column.

Rule 3 — Column Name should be unique

  • Each Column should have a unique Name. Same name leads to confusion at the time of data retreivel.
