Step 1: The Small Numbers 👀

  • Integer x = 100; → Sets x to 100.
  • Integer y = 100; → Sets y to 100.
  • x == y → Check if they’re the same thing.
Here’s the fun part: Java has a secret stash for numbers -128 to 127. It reuses 100 from that stash, so x and y are the same. Prints: true! Easy so far 😄?

Step 2: The Big Switch 🔄

  • Integer bigX = 1000; → Sets bigX to 1000.
  • Integer bigY = 1000; → Sets bigY to 1000.
  • bigX == bigY → Check if they’re the same thing.
But wait! 1000 is too big for Java’s stash. It makes new objects for bigX and bigY. They’re different, so it prints: false! Tricky, right?

The Answer

true
false
Did you guess it? Woo-hoo if you did 🙌!

Why It Tricks You

Java hides a stash for small numbers (-128 to 127).

== checks if they’re the same object, not just the same value.
Small numbers share, big ones don’t — it’s a sneaky trap! You might think “same number, same result,” but nope!
