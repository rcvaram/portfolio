AWS — EC2

Elastic Compute Cloud

AWS — EC2

  •  Elastic Compute Cloud
  • Can be looked at as virtual machines in the cloud.
  • Storing data on virtual drives (EBS).
  • Distributing load across machines (ELB).
  • Scaling the services using an auto-scaling group. 
  • Linux, Windows or Mac OS can be used as Operating System
  • Following configurations can be done when we set up the EC2 instance in AWS.
1. How much CPU 
2. How much Memory (RAM)
3. How much Storage Space
4. Network card Speed
5. Firewall Rules(Inbound and Outbound Rules) 6. Bootstrap Script(Which can be run at first launch — EC2 User Data)

To Launch a new Ec2 instance

  1. Choose AMI
    An AMI is a template that contains the software configuration (OS, application server and application) required to launch the instance.
     → AWS AMIs
     → User Community
     → AWS Marketplace
     → Own AMIs
  2. Choose Instance Type
    A wide selection of instance types is optimized to fit different use cases. Each Instance type has varying combinations of CPU, memory, storage and network capacity. 
  3. Configure Instance
    How many instances, request spot instances to take advantage of the lower pricing, assign an IAM Role and add user data that can be run in boot time, can be done in this section. 
  4. Add Storage
    We can attach EBS volumes and instance store volumes to the instance to edit the settings of root volume. When we terminate the instance we can delete the storage as well if we want.
  5. Add Tags
    Tags are used by us to interpret various resources. 
  6. Configure Security Group
    A security group is a set of firewall rules that control the traffic of the instance. We can add rules to allow specific traffic to reach the instance. 
  7. Review
    Review the configurations of the e2 instance

When you try to launch the instance, you will end up with select an existing key pair / creating a new key pair. A RSA key pair consists of a public key that AWS stores and a private key that needs to be stored from your site. To connect the instance via SSH, you need to provide the private key then AWS will validate with its public key. then it allows you to connect the instance securely. 

Security Groups 

 Security groups are the fundamentals of network security in AWS. They control how traffic is allowed into or out the EC2 instance

Security groups only contain allow rules

Security group rules can reference by IP or by security group

Security groups are acting as a firewall on EC2 instances.
