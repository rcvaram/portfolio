A Quick Connection on Flask with SQLite

Here, I don’t talk about everything just focus on connecting the SQLite database with the Flask application

SQLAlchamey → It is commonly used for Object Relational Mapper(ORM) to work with different databases such as SQLite, MySQL and more. It allows us to use the database in an object-orientated way. Most of the time, Most of the python code doesn’t need to change for different databases If you use ORM type.

How can we do get the support of SQLALchamey in Flask?

We need to install the pip package which named flask-sqlalchemy

pip install flask-sqlalchemy

This flask specific sqlalchemy package gives more helpers for our flask application.

Connecting the SQLite database with our Flask Application

SQLite is the easiest way to test your application then you can change your database to anything you want.

Bolded lines are only needed for SQLite configuration for flask application.

from flask_sqlalchamey import SQLAlchemy
app = Flask(__name__)
app.config['SECRET_KEY'] = "SECRTETbROOOOOO"
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///test.db'
db = SQLAlchaemy(app)
  1. We need to import the SQLAlchemy from the flask_sqlalchamey. 
  2. We need to say where the database is located in our flask app directory. It can be done with SQLACHEMY_DATABASE_URI configuration. Here, We set our path as “sqlite:///test.db”. In this path, we specify what database we will use and after ///, we specify our relative database base path from the current file.
  3. We need to get the SQLAlchamey class instance to work with our database. Since we specified the database URL to the flask app, We only need to give the Flask app instance as an argument to the SQLALchemy constructor. Inhere, we get the SQLAlchemy instance as DB.
