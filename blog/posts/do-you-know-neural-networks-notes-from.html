Do you know Neural Networks? — Notes From  

Neural networks act as a ‘black box’ brain that takes inputs and predicts outputs. It’s different and better than most traditional machine learning algorithms because it learns complex non-linear mappings to produce far more accurate output classification results.

How NNs ‘look’

A simple neural network with 1 hidden layer


These two inputs are, for example, like a pixel in an image. These hidden nodes are the black box that we have talked about. The output should be like a cat or dog.


Forward Propagation

How Neural networks process their input to produce an output. Normally, the inputs are numerical or categorical.

Each Hidden node is connected with each input. There are also weights put there. What these weights we will see later. We need to remember that each connection has weight and there is another value B1. B1 is simply a constant. In reality, each weight has its constants. This is called bias for the input.

All are just maths O= W*I+B

We might not get the required outputs because,

  1. Our initial default random weights (w and b) produced very incorrect results.
  2. Feeding numbers through a neural network is a matter of simple matrix multiplication.
  3. Our neural network is still just a series of linear equations.

Activation Functions

In reality, each hidden node also passes through an activation function. In the simplest terms, an activation function changes the output of that function. For example, let’s look at a simple activation function where values below 0 are clamped to 0, meaning negative values are changed to 0.


output = Activation(wx+b)
f(x) = max(0, x  )



  1. ReLU Activation Function

This activation function is called the ReLU (Rectified Linear Unit) function. This is one of the most commonly used activation functions in training neural networks.

Most ML algorithms find non-linear data extremely hard to model. The huge advantage of DL is the ability to understand non-linear models


It takes the following appearance. the clamping values at 0 account for its non-linear behaviour.

f(x) = max(0,x)

What ReLU does is basically forward the positive values as they are and change the negative values to zero. The output should be greater than equal to zero.

Let’s Talk about BIAS

Biases provide every node/ neuron with a trainable constant value, allowing us to shift the activation function output left or right.

Weights change only the gradients or steepness of the output; they will not shift the curve. For that, we need bias to shift the curve.

Below first one is only weights are added and the next one is only bias is added.

Neuron only fires when an input threshold is reached. Neural networks follow this principle.

Loss Functions

As we know random weights give bad results. What we need is a way to figure out how to change the weights so that our results are more accurate. This is where the brilliance of Lose Functions, Gradient Descent and backpropagation show their worth.

Some labelled data we need to train the neural network.

Training step-by-step

  1. Initialize some random values for our weights and bias.
  2. Input a single sample of our data(Forward propagation step)
  3. Compare our output with the actual value it was supposed to b, we’ll be calling this our Target values.
  4. Quantify how inaccurate these random weights were, we will call this our loss
  5. We will adjust weights in the next generation so that the loss lower
  6. Keep doing this for each sample in our dataset
  7. Send the entire dataset through this weight ‘optimization’ program to see if we get an even lower loss
  8. Stop training when the loss stops decreasing

Quantifying loss with loss functions

Loss functions are integral in training neural nets as they measure inconsistency or difference between the predicted results and the actual target results.

They are always positive and penalize the big errors well.

The lower the loss the better the model

There are many loss functions. Mean Squared Error(MSE) is popular.

MSE =(Target -predict)²


Other types of loss fucntions

  1. L1
  2. L2
  3. Cross entropy — used in binary classifications
  4. Hinge Loss
  5. Mean Absolute error

BackPropagation and Gradient Descent

Both of them are used to efficiently determine the best weights. What if there was a way we could use the loss to adjust the weights? That is the brilliance of backpropagation. Backpropagation tells us how much a change in each weight affects the overall loss.

Using the MSE obtained from Output1 backpropagation allows us to know

  1. If changing w5 from 0.6 by a small amount like 0.0001 addition or subtraction how do they affect the overall loss whether they increase the loss or decrease the loss?
  2. We backpropagate this loss to each node( Right to Left) to determine which direction the weight should move(negative/positive)
  3. We do this for all nodes in the neural network

Backpropagation full cycle

  1. Therefore, by simply passing one set of inputs of a single piece of our training data, we can adjust all weights to reduce the loss or error.
  2. However, this tunes the weights for that specific input data How do we make our neural network generalize?
  3. we do this for each training sample in our training data( called an Epoch or iteration)

Naive Gradient Descent is very computationally expensive as it requires exposure to the entire dataset and then updating the gradient.

Stochastic gradient descent does the updates after every input sample. This produces noisy or fluctuating loss outputs. However, again this method can be slow.

Mini Batch Gradient Descent is a combination of the two. It takes a batch of input samples and updates the gradient after that batch is processed( batches are typically 20–500, though no clear rule exists.) It leads to must faster training.

Regularization, Overfitting ,Generalization

What makes a good model?

  1. A good model is accurate
  2. Generalizes well
  3. Does not overfit

The red line is our decision boundary for each model. Model A separates all the data accurately. Model B has a smooth curve it doesn’t push itself out here to capture this blue ball and it forms a nice clean decision boundary. Model C takes a much more simplistic approach giving you a straight line separating these boundaries. So what is the best model here?

It will be Model B why? Nataure of the data you can see that the blue ball technically in the green region. This ball is an anomaly. basically it is an outlier. The blue ball which is in green region is unusual. Model A is called overfitting. Model C is underfitting. C doesn’t fit the data well.

Overfitting leads to poor models and is one of the most common problems faced in developing AI/ML/NN.

Overfitting occurs when our model fits perfectly to our training data, as we saw in the previous slide with model A. However, fitting too closely to train isn’t always a good thing.

  1. What happens if we try to classify a brand new point that occurs at the position of the blue
  2. It will be classified because our model has overfitted the test data
  3. Models don’t need to be complex to be good.

How do we know if we are overfitting?

Test on your model on ….. Test Data!

in all ml, we must hold back a portion of our data(10–30) as pure untouched test data. untouched data meaning that this data is never seen by the training algorithm. It is purely to test the performance of our model to assess it’s accuracy in classifying new never-before-seen data.

Many times when overfitting we can achieve high accuracy 95% ON OUR train dATA but then get 70 % results on the test data. Good training accuracy but poor test accuracy that is overfitting.

TO Avoid Overfitting

We can use fewer weights to get smaller/less deep neural networks. deeper models can sometimes find features or interpret noise to be important in data. due to their abilities, tom memorize more features(called memorization capability)

Regularization can be avoided the overfitting

It’s better to practice to regularize than reduce our model complexity.

What is Regularization

It is a method to generalize the model. Regularisation Wii take a model that produces a decision boundary and makes it, tweak it so that it becomes like balanced one.

Types of Regularization

L1 & L2 Regularization
Cross-Validation
Early Stopping
Drop out
Dataset Augmentation

L1 & L2 Regularization

These are the techniques we use to penalize large weights, Large weights manifest as sudden changes in our model’s decision boundary. by penalizing we are really making the smaller.

Here lambda controls the degree of the penalty we apply. Via Backpropagation, the penalty on the weights is applied to the weights updates. Difference between L1 and L2 is L1 brings the weights of the unimportant features to zero thus acting as a feature selection algorithm (Like a sparse model).

Cross-validation or also know as k-fold cross-validation is a method of training where we split our dataset into k folder instead of a typical training and test split.

For example, let's say we’re using 5 folds. we train on 4 and use the 5th final fold as our test. we then train on the other 4 folds and test on another. we then use the average weights across comping out of each cycle. Cross-validation reduces overfitting but slows the training process.

Early Stopping 


When the loss starts to increase we can stop the process.

Dropout refers to dropping nodes (both hidden and visible) in a neural network with the aim of reducing overfitting. This helps to reduce interdependent learning amongst the neurons. Thus the NN learns more robust or meaningful features.

Some terms

Epochs

An Epoch occurs when the full set of our training data is passed/ forward propagated and then backpropagated through our network. After the first epoch, we will have a decent set of weights, however, by feeding our training data again and again into our neural network we can further improve the weights this is why train for several epochs happened.

Batches

When we don't have a huge amount of GPU/RAM, we need to split our training data into segments or BATCHES. Batch size is the number of training samples we sue in a single batch. 1000 samples split into 100 of 10 batches then batch size is 100 no of batches 100.

Iterations 

Many confuse iterations and Epochs(I was one of them). However the difference is quite simple. Iterations are the number of batches we need to complete on epoch.

Measuring Performance

There are lot of things more than accuracy to determine the model performance. 

Accuracy is simply a measure of how much of our training data did our model classify correctly

Lose values go up when classifications are incorrect.

While accuracy alone doesn't tell the whole story. 


Recall — How much of the positive classes did we get correct

Precision — our of all the samples how much did the classifier get right

F-Score — Is a metric that attempts to measure both recall & precision
