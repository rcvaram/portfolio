Best Overview of ML

Machine learning is almost synonymous to artificial intelligence because it entails the study of how software can learn

It is a subfield of artificial intelligence that uses statistical techniques to give computer systems the ability to learn from data. without being explicitly programmed. 

It has seen a rapid explosion in growth in the last 5–10 years due to the combination of incredible breakthroughs with Deep learning and the increase in training speed bought on by GPUs.

There are four types of machine learning with neural networks that are arguably the most powerful ML algorithm. These types are

  1. Supervised Learning
  2. Unsupervised Learning
  3. Self- supervised learning
  4. Reinforcement learning 

in Supervised learning, We take a set of labelled data(called a dataset) and we feed it to some ML learning algorithm that develops a model to fit this data to some outputs.

Unsupervised learning is concerned with finding interesting clusters of input data. It does so without any help from data labeling. It does this by creating interesting transformations of the input data.

Self-Supervised learning is the same concept as supervised learning. however, the data is not labelled by humans. Typically, Using a heuristic algorithm, labels are generated. Autoencoders are the best example of this.

Reinforcement learning is potentially very interesting but hasn’t become mainstream in the AI world just yet.

The basic process is used in ML supervised learning

  1. Obtain a labelled data set
  2. Split dataset into training and test potion.
  3. FIT Model to the training dataset
  4. Evaluate models performance on the test data

ML Terminology

. Target — Ground truth labels

. Prediction — The output of your trained model given some input data

. Classes — The categories that exist in your dataset e.g a model that outputs Hender has two classes

. Regression — Refers to continuous values like someone’s height

. Validation/Test They can be different. generally refers to unseen data that we test our trained model.
