Kafka Customer → Get Specific Messages Only

This is not a traditional spring Kafka consumer setup where the consumer actively listening to a particular topic. Kafka Customer can retrieve the message from the specified offset of the topic.

Why we need

Spring Kafka has a pattern to listen to topics actively(Kafka listeners). that’s what we need most of the time. In some cases, we don't need to listen to the topic actively.

  • To test the message which we sent to Kafka was correct or not.
  • Retry a missed Kafka offset message.

So above two cases, we need to get the message of specified offset.

Existing methods

This is possible with Kafka console consumer (https://kafka-tutorials.confluent.io/kafka-console-consumer-read-specific-offsets-partitions/confluent.html). but there is no handy method in spring Kafka and actually It is not difficult to code as well.

Spring Kafka way

We have to deal with this with our implementation

Spoiler Alert

We didn't do any fancy work, We just use the Spring Kafka Consumer to get the particular message

We use the existing SpringKafkaConsumerFactory, and also we are extending our KafkaCustomer with Spring AbstractConsumerSeekAware abstract class. We use Spring AbstractConsumerSeekAware to manage the ConsumerSeekAware.ConsumerSeekCallback s for the listener. it can easily seek arbitrary topics/partitions without having to keep track of the callbacks themselves.

Since Kafka Consumer is not threadsafe. we added ReentrantLock for that.

KafkaCustomerImplementation

First, we try to get the lock.

final boolean isAvailable = reentrantLock.tryLock(lockTimeOut, TimeUnit.SECONDS);

If we are able to lock, then we assign the SpringKakfaConsumer to a specific TopicPartition.

final Map<TopicPartition, Long> topicOffsetMap = Collections.singletonMap(new TopicPartition(topic, partition), topicOffset);
consumer.assign(topicOffsetMap.keySet());

then we set the seek offset where the SpringKafkaConsumer needs to look on the topic.

topicOffsetMap.forEach(consumer::seek);

We resume the consumer to poll.

consumer.resume(topicOffsetMap.keySet());
final ConsumerRecords<K, V> poll = consumer.poll(Duration.ofSeconds(maxPollSeconds));

once SpringKafkaConsumer gets the record we verify that the offset is the correct one.

for (ConsumerRecord<K, V> kvConsumerRecord : poll) {
    if (kvConsumerRecord.offset() == topicOffset) {
        consumerRecord = kvConsumerRecord;
    }
}

After that, we commit the consumer in a synchronous way. We pause the consumer for the topic partition.

consumer.commitSync();
consumer.pause(topicOffsetMap.keySet());

Once this happened, we release the lock.

reentrantLock.unlock();

So we will receive specified offset consumer records with the help of KafkaCustomer.

How to use

import the dependency in your spring Kafka maven or Gradle project.

Create a KafkaCustomer with your SpringKafkaConsumerFactory as follow. For simplicity, I have used String classes for Key and Value Classes, You can use your Kafka classes.

ConsumerFactory<String, String> consumerFactory;            
KafkaCustomer<String, String> kafkaCustomer = new KafkaCustomer<>(consumerFactory, 1000, 5);

Create the topic partition and offset Mapper

TopicPartition topicPartitionZero = new TopicPartition("test",1);
 TopicPartition topicPartitionOne = new TopicPartition("test",0);
 Map<TopicPartition, Long> map= new HashMap();
 map.put(topicPartitionZero, 5);
 map.put(topicPartitionOne, 6);
 Map<TopicPartition, ConsumerRecord<String, String>> OffsetValueMapper = kafkaCustomer.get(map);

Now, you can use offsetValueMapper to get the values.
