Introduction to Spring Boot

What is Spring Boot?

Spring framework is used to write java enterprise application this is very huge framework and the boot is bootstrap spring boot something let you bootstrap a spring application from the scratch. The official documentation What they say is spring boot is easy to create stand-alone production-grade spring based applications, that you can just run. So this is a just a tool to create spring application but It is stand-alone and production-grade so it means, The java application is not a hello-world and it can be deployed as a product. If you create spring application without spring boot there is lot of pain. A lot of configurations, more jar files you want to import in spring. So we have to look those problems.

Spring frameworks problems

It was application frame work. Dependency injection concept is the origin of spring framework but now it has many functionalities. Spring provide template or frame work to build enterprize application. Spring handles lot of common things which every Java enterprize application has. Spring handles querying the database, HTTP method handling also spring frame work provides infracture support. So many different things solution has been solved using spring. So it was huge framework and It has multiple setups. As general example, spring can connect to mongodb, RDMS and other databases. this is the case of database connecting like this we have multiple setup process So that needs all configurations to create a new project. After creating the project, we want to build and deploy and we have to deploy in a server as well. So we are focussing on configuration more than business logic.

We can start the application with the configuration of spring boot then we can change the configuration with our requirements. It creates stand alone. When we build Spring application we have to deploy in servelet container like tomcat here, we don’t need to configure the tomcat or run the tomcat in separately so How we can deploy? that was the next section.

When we build spring application we have to manage the dependencies. We have to import some JAR files to our application. When we import Jar files, we can use their java classes to our application as well. For this dependency management we can use Maven or gradle in spring application. For now, I have planned to use maven. In maven, We can delcare all dependecies in a single file which is called as pom.xml. Here, we can mention what JAR files we want. Here we have list of dependencies in pom file which maven wants to know. Thne maven knows, these are the deendencies this application needs. Maven looks at the repo and downloads the required dependencies for the application.

Get Started

We are going this initializer web site to create our projecct. Group id is just like a kind of package name nad the artifact id is kind of an application name

If you look at the main class of the spring boot application you can see a annotation like @SpringBootApplication annotation in the top of the class

This annotation will tell the spring boot that this is the starting point or entry point of the application. The main method should tell to the spring boot that you need to start this application and create servlet container and host this application in that container. How can we do those things in the main method becuase you are using spring boot. So you can do it with one line that is you will call the run static method of spring boot application SpringApplication.run(<Your main class name>.class, args);

What this run method is doing

sets up Default configurations 

Starts the spring application context 

Performs class path scan

Start up the tomcat server

OK now we have the spring boot application without doing nothing
