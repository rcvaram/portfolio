What is Thread Pool Task Executor?

ThreadPoolTaskExecutor is an abstract view of ThreadPoolExecutor from Spring. Since this is an abstract we may mess up with its configurations. let's see what each parameter describe

CorePoolSize

The maximum number of threads that can be created by the executor without adding the task to the queue.

MaxPoolSize

The maximum number of threads that can be created to take the tasks from the queue when the queue is full.

Queue

The queue is used to add the task when core threads are not available.

Let’s think this way

SpringPoolTaskExecutor is a guy who executes the task with a pool of threads. He is responsible for producing/managing threads.

You give the below instruction to ThreadPoolTaskExecutor

  1. CorePoolSize = 5
  2. MaxPoolSize = 15
  3. Queue = 10

Now, You instruct the SpringPoolTaskExecutor hence SpringTaskExecutor behaves as you wish.

How ThreadPoolTaskExecutor(TPTE) decides when to create a thread.

When a new task arrived at TPTE. TPTE checks how many threads it’s already created

  • if the threads in the thread pool(3) are less than the core pool thread size(5) then it will create another thread and give that task to a new thread.
  • If the threads in the thread pool(6) are greater than equal to the core pool size (5) then it will add the task to the queue(tasks in queue = 2) while the queue is not full. so Later, core threads finish their task, and they can take it from the queue.
  • If the threads in the thread pool(6) are greater than equal to the core pool size (5) and the queue is also filled(tasks in queue =10) then TPTE checks the number of threads(15) is less than the max pool size or not. If it is less than that, then it will spawn a new thread(Total threads in the pool will be 6).
  • If the threads in the thread pool(15) are greater than equal to the core pool size (5) and max pool size (15) and the queue is also filled(tasks in queue =10) then TPTE can not hold the task hence the task will be rejected and it will immediately throw a TaskRejectionException.
