What is the batch workload?

AWS Fargate on AWS Batch


What is the batch workload?

Jobs that can be run without user interaction or can be scheduled to run as resource permits.

  1. They do not interact tightly with an end-user
  2. These jobs are commonly run in the background
  3. Compute with high memory to vCPU ratio
  4. Execution on trigger or schedule
  5. Parallel with managed queues 
  6. Monitoring & Alerts
  7. Resilient to failures
  8. Secure and compliant
  9. Flexible scheduling for lower costs.

Amazon ECS & Fargate

  • Amazon ECS → Deployment, scheduling, scaling and management of containerized applications.
  • Hosting → Where the containers run. It can be Fargate or EC2

Why run batch workloads on Amazon ECS/Fargate?

  1. Secure by default → Single tenant VM isolation, automatic patching and encryption
  2. Serverless compute → No Ec2 instances to provision, manage or scale. On-demand
  3. Compliance → ISO, PCI, SOC & HPAA-eligible
  4. Saving → On-demand & Spot pricing
  5. Integrated → Integrates with AWS

Fargate task CPU memory Configurations

  1. 0.25 vCPU with (512MB, 1GB and 2 GB)
  2. 0.5 vCPU with 1GB, 2GB, 3GB, 4GB

Scheduled / Triggered batch jobs

  1. Writing a cloud watch event rule → It will trigger the scheduled task in ECS/Fargate

Advantages

  • Easy to setup
  • Automated
  • Serverless
  • Several AWS + partner trigger events supported
  • Logging, metrics and alerts with amazon cloud watch

Disadvantages

  • Retry on Failures is not setup here

Improve batch job resiliency

Additional benefits with step functions.

  • Define JSON, visualise in console, monitor execution
  • State machine monitors job health
  • Failed jobs can retry
  • Define timeout
  • Add notifications

AWS Copilot CLI: Scheduled Jobs (New)

  • New Amazon ECS command line experience
  • Rapid application development by automatically provisioning lower-level infrastructure
  • schedule jobs with build timeouts and retries

AWS Batch on AWS Fargate (New)

  • Serverless batch computing
  • AWS provides managed batch queue, with priority, dependencies, retry configuration and lifecycle management
  • Process thousands of jobs in parallel at scale with resiliency
