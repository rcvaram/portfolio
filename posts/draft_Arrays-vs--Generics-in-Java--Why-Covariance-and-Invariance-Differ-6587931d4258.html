Arrays vs. Generics in Java: Why Covariance and Invariance Differ

Hey, you ever wondered why arrays and generics act so differently in Java? One is like a flexible friend, and the other is a strict sister. Let’s make it easy — what are they, and why don’t they play the same?

What’s an Array?

Arrays are like a row of boxes. Each box holds something.

int[] numbers = new int[5];
Dog[] dogs = new Dog[3];


 They’re 

  • old
  • simple
  • fast 

Java has been using them since 1995. 

What’s a Generic?

Generics are newer compared to Array — Java got them in 2004. They’re like smart bags that only hold one kind of thing. Like: List<String> for words, or List<Dog> for dogs.

List<Dog> dogs = new ArrayList<>();

They’re safe because Java checks everything before running the code.

Arrays: Flexible and Fun

Arrays are covariant. That’s a big word — it means they bend a little.
If a Dog is a type of Animal, then a Dog[] can act like an Animal[].

Dog[] dogs = new Dog[3];  
Animal[] animals = dogs;

Cool, right? Dogs are animals, so it feels okay.

But watch out:

animals[0] = new Cat(); // Java says yes, but then - oops!
It crashes when you run it — cats aren’t dogs.
Java checks this late, so you have to be careful. Arrays are like a fun friend who sometimes tricks you.

Generics are invariant. That means no bending — List<Dog> stays List<Dog>.It can’t be List<Animal>.

List<Dog> dogs = new ArrayList<>();  
List<Animal> animals = dogs; // No way—Java stops it!

Why so serious? To keep you safe!

Imagine if it worked: animals.add(new Cat()); Then dogs.get(0) grabs a cat — big problem!.Java says “NO” before you run the code.

No surprises — generics are like a strict Sister.

Wildcards: A Little Help

Want some fun with generics? Try wildcards.

List<? extends Animal> animals = dogs; // You can look, not touch.
 Animal a = animals.get(0); // Okay!
 But animals.add(new Dog()); // Nope - Java says "too risky."

Or try this:

 List<? super Dog> stuff = new ArrayList<Animal>();
 stuff.add(new Dog()); // Works — dogs fit!
It’s like a half-strict, half-fun rule.

Extra Cool: Java 21’s Sealed Classes

New Java has sealed classes. Like: sealed interface Animal permits Dog, Cat {} 

Dog[] can still be Animal[] — flexible as always. But List<Dog>? Still strict, no change. It’s a fun twist, but the old rules stay.
