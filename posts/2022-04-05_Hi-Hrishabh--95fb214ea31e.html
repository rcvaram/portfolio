Instead of writing logic handling for each case, We had a map , put the case and the logic as key, value pair.

Hence, We can retrieve the logic from the map based on key.

I started with if else because, most of us(devs) start with if-else. but it is actually a nice replacement for switch case with so many options.

Also, I wanna say, I don't recommended to use this in simple logic related switch cases since as yo said, it will increase the complexity in code readability. .

I prefer this when your class main functionality implementation depends on the switch case (Strategic pattern).
