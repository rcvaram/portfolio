What is a Randomized Algorithm?

The algorithm which takes decisions based on random choices that are generated during its execution is called a randomized algorithm. …. 
 Got it Ryt?

Yes, I know, It's difficult to understand so I came up with a problem that can be solved with randomized algorithm So we can easily understand this.

Hiring problem

Imagine you are a recruiter and you need to recruit someone who is sent by the agency to replace a current employee.

Basically, you need to hire the best person compared to the current employee.

You know, the agency never gives free offer You need to pay a fee for the agency.

  • Interview fee → You need to pay the agency a small fee for an interview
  • Hiring fee → You need to pay the agency a large fee when you decide to hire a person.
A note → your company always want to have a best person

If the interviewed person is better than a current employee then hire the new person.

Let’s take an assumption, You need to pay interview fee + hiring fee when you hire a person and you may already hire a person with that amount and a next day the interviewed person is better than your hired one then also you need to hire the person and pay interview fee + hiring fee.

I believe the problem is clear, So

how can you estimate payment for the agency?

Our candidates are named as 1,2,3 …. n for simplicity

After interviewing candidate i, determine if i is the best person so far then we hire him

Costs are defined as following

Interview fee — Ci

Hiring fee — Ch

Let’s write a small algorithm with python

current_employee, Ci, Ch;// define Ci, Ch, current employee
cost = 0
def hire_assitant(candidates):
    for i in range(len(candidates)):
        candidate = get_candidate(candidate[i].name)
        result = interview_candidate(candidate)
        if result == "hired":
           cost = cost + Ci + Ch
        else:
           cost = cost + Ci
def interview_candidate(candidate):
    if candidate is better than current employee:
       current employee = candidate
       return "hired"
    else:
       return "Not hired"
def get_candidate(candidate_name):
    return the candidate to the interview by agency

So basically the cost equation is like below

cost = nCi * mCh 
where m people hired from n candidates and If Ci small we can focus only mCh

Worst-case Scenario

In the worst case, we will hire all the persons where everyone is best compared day before hired one. then The cost will be nCh (n and m are same).

But in likelihood, it will not happen,

We need to have a random order to select a candidate for the interview. So that what we can do is, we ask the agency to give candidates list. then we can select a random person for an interview for each day. It makes us reduce to get the worst-case probability. How can we do that? Here we make our algorithm to a randomized one.

Simply we shuffle the list before asking the agency to bring the people.

So our algorithm will be like below

current_employee, Ci, Ch;// define Ci, Ch, current employee
cost = 0
def hire_assitant(candidates):
    candidates = shuffle(candidates)
    for i in range(len(candidates)):
        candidate = get_candidate(candidate[i].name)
        result = interview_candidate(candidate)
        if result == "hired":
           cost = cost + Ci + Ch
        else:
           cost = cost + Ci
def interview_candidate(candidate):
    if candidate is better than current employee:
       current employee = candidate
       return "hired"
    else:
       return "Not hired"
def get_candidate(candidate_name):
    return the candidate to the interview by agency

We make the choice for the next candidate as a random choice by shuffling the list. This is done within the algorithm. Our input (candidates list) may be random one or preorder one but our algorithm makes it as random and take its decision based on random choice

Now Look the definition

Algorithm which takes decisions based on random choices that are generated during its execution is called randomized algorithm.

In our hiring algorithm takes the candidate randomly within its algorithm. So these kinds of algorithms are called randomized algorithms.

Some key points on a randomized algorithm

  • This makes us reduce the probability of the worst-case scenario
  • An algorithm that makes random choices during its execution
  • These random choices are used to make decisions
  • It makes no bad inputs but may have a bad random choice (Candidate list may be sorted in worst to best but that is not a problem since we shuffle it inside the algorithm)

When we can use this approach

When we have so many ways to proceed and at the same time we difficult to find a way that can be guaranteed good then we can choose this approach. Here, we get good ways but may not get the exact best way.
