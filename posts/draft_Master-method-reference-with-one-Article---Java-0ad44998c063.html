What is Method Reference?

We know that Lambda expressions allow us to assign a block of code to a variable or pass it as a parameter. 

But what if the code inside the Lambda is simply calling an existing method?

 For example:

Consumer<String> printer = s -> System.out.println(s);

Here, the Lambda s -> System.out.println(s) does nothing but call an existing method: System.out.println(s). 

Java 8 introduced method references to simplify such cases. 

A method reference is a shorthand syntax for a Lambda expression that directly invokes an existing method. 

The above code can be rewritten as:

Consumer<String> printer = System.out::println;

The :: syntax denotes a method reference.

It tells the compiler to reuse the existing method println from System.out as the implementation of the Lambda.

method references allow you to refer to methods by their names instead of writing full Lambda expressions.

What Type Should the Variable Have?

method references are used in the context of functional interfaces (interfaces with a single abstract method). 

Functional interfaces are interfaces which consist a single abstract method 

The method reference must match the signature of the functional interface’s method.

  • System.out::println matches the Consumer<String> interface because println accepts a String (and returns void).
  • String::length matches Function<String, Integer> because length() takes no arguments and returns an Integer.

What is the Function of Method Reference?

The aim is to eliminate boilerplate code when the Lambda’s body is just a direct call to an existing method.

Method References brings code as more concise and readable

Let’s compare Lambda expressions and method references in common scenarios.

Static Method Reference

Static Normal Function

public static boolean isAdult(Student s) {
    return s.getAge() > 17;
}

Lambda Approach

Predicate<Student> adultTest = s -> Student.isAdult(s);

Method Reference Approach

Predicate<Student> adultTest = Student::isAdult;
If a Lambda passes its parameter directly to a static method, replace s -> Class.method(s) with Class::method.

Instance Method of an Arbitrary Object

Normal Function

public class Student {

  private String name;
  public String getName() {
      return this.name;
  }

}

Lambda Approach

List<String> names = students.stream()
                             .map(s -> s.getName())
                             .toList();

Method Reference Approach

List<String> names = students.stream()
                             .map(Student::getName)
                             .toList();
