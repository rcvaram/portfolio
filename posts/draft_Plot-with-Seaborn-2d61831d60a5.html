Plot with Seaborn

Data visualization is a challenging task but the seaborn makes it simple. First Thing is what is seaborn? 

Seaborn is a data visualization library available in python. The core of this library is matplotlib. It allows you to create statistical graphics. It has more features like comparing multiple variables, supporting multi-plot grids, creating univariate and bivariate visualizations, creating the graphs estimating and plots linear regression

Easy things easy & hard things possible seaborn makes well-defined set to hard things easy too. matplotlib is good but seaborn is better

Normally, data analytics will be using the Pandas library. Matplotlib doesn’t serve well when it comes to dealing with dataframes while seaborn functions actually work on dataframes. If you are working on Pandas then seaborn is for you.

How to install the seaborn?

If you are using python3 then you can use pip3 to install the seaborn

pip3 install seaborn

When you are using the python 2, You can install with pip

pip install seaborn
