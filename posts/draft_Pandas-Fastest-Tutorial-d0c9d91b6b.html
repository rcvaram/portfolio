Pandas Fastest Tutorial 

DataFrame can be looked at as a dictionary that contains keys and a list of values per each key.

Access a single column in Dataframe

df['ram']


df.ram

This is a series type which can be looked at as a list.

Prefer convention access like key rather than dot convention since There are chances that the data frame contains methods or attributes in the same column name.

access multiple columns of a dataframe

df[[ 'ram', 'harddisk']]


This is not a series its another dataframe

access a row of a dataframe

df.iloc[0]


df.loc[2]


iloc → integer location of row

loc → label location index

we can change the indexvalues then using loc function we can get the row

select multiple rows of a dataframe

df.iloc[[0,1,2,4]]


df.loc[[1,2]]

select multiple rows of a dataframe with specific columns

df.iloc[[1,3,4,34], 2]


df.loc[[1,2], "ram"]
df.loc[[1,2], ["ram", "harddisk"]]

using iloc 2 is the 3rd column of the dataframe


get the first 5 rows

df.head(5)


Setting a custom index for the dataframe

df.set_index(["hp","del", "mac", "lenavo"] inplace =True)

inplace argument used to whether dataframe change or not.

resetting index for the dataframe

df.reset_index(inplace=True)
