Deploying a Spring Boot (Java 21) Application on AWS EC2 with GitHub Actions and API Gateway [Free]

Deploying a Spring Boot application on AWS does not have to be complex or expensive.
 In this article, we will walk through a simple, low-cost, and production-ready setup using:

  • Spring Boot (Java 21)
  • AWS EC2
  • systemd for process management
  • Nginx as a reverse proxy
  • GitHub Actions for CI/CD
  • API Gateway (HTTP API) for HTTPS access

This approach avoids Docker and focuses on clarity and control.

Final Architecture

GitHub (develop branch)
        ↓
GitHub Actions (CI/CD)
        ↓
EC2 (Amazon Linux 2023)
 ├─ Spring Boot JAR (Java 21)
 ├─ systemd service
 └─ Nginx (port 80)
        ↓
API Gateway (HTTPS endpoint)

Authentication (JWT / Cognito) is handled inside the Spring Boot application, not in API Gateway.

Step 1: Create an EC2 Instance

  1. Go to AWS Console → EC2 → Launch Instance
  2. Use the following configuration:
  • Ami — Amazon Linux 2023
  • Instance Type — t3.micro
  • Auto Assigned IP — Enabled
  • Storage — Default
  • Key Pair — Create or Use Existing

Security Group (Inbound Rules)

  • SSH 22 Your IP address
  • HTTP 80 all
  • HTTPS 443 all

Once launched, note the public IP address.

Step 2: Connect and Prepare the Server

SSH into the instance:

ssh ec2-user@<EC2_PUBLIC_IP>

Update the system:

sudo dnf update -y

Install Java 21 and Nginx:

sudo dnf install java-21-amazon-corretto nginx -y

Verify installation:

java -version
nginx -v

Enable and start Nginx:

sudo systemctl enable nginx
sudo systemctl start nginx

Step 3: Run Spring Boot as a systemd Service

Upload your JAR file to:

/home/ec2-user/acc360-api.jar

Create a systemd service

sudo nano /etc/systemd/system/acc360.service

Paste the following:

[Unit]
Description=acc360 Spring Boot API
After=network.target
[Service]
User=ec2-user
WorkingDirectory=/home/ec2-user
ExecStart=/usr/bin/java -jar /home/ec2-user/acc360-api.jar
SuccessExitStatus=143
Restart=always
RestartSec=5
[Install]
WantedBy=multi-user.target

Enable and start the service:

sudo systemctl daemon-reload
sudo systemctl enable acc360
sudo systemctl start acc360

Check status:

sudo systemctl status acc360

At this point, Spring Boot should be running on port 8080.

Step 4: Configure Nginx as a Reverse Proxy

Edit the Nginx configuration:

sudo nano /etc/nginx/nginx.conf

Use this minimal configuration:

server {
    listen 80;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header Authorization $http_authorization;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
⚠️ Important: Do not add a trailing slash to proxy_pass.

Reload Nginx:

sudo nginx -t
sudo systemctl reload nginx

Test:

curl http://<EC2_PUBLIC_IP>/api/accounts

Step 5: Automate Deployment with GitHub Actions

Create SSH Key for CI/CD

On your local machine:

ssh-keygen -t rsa -b 4096 -f acc360-github

Add the public key to EC2:

nano ~/.ssh/authorized_keys

Paste the contents of acc360-github.pub.

Add GitHub Secrets

In GitHub repository settings → Actions → Secrets:

SecretValueEC2_HOSTEC2 public IPEC2_USERec2-userEC2_SSH_KEYPrivate key content

GitHub Actions Workflow

Create:

.github/workflows/deploy-develop.yml
name: Deploy acc360-api to EC2 (develop)
on:
  push:
    branches:
      - develop
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '21'
      - run: chmod +x ./gradlew
      - run: ./gradlew clean bootJar
      - name: Copy JAR to EC2
        uses: appleboy/scp-action@v0.1.7
        with:
          host: ${{ secrets.EC2_HOST }}
          username: ${{ secrets.EC2_USER }}
          key: ${{ secrets.EC2_SSH_KEY }}
          source: "build/libs/*.jar"
          target: "/home/ec2-user/"
          overwrite: true
      - name: Restart Service
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.EC2_HOST }}
          username: ${{ secrets.EC2_USER }}
          key: ${{ secrets.EC2_SSH_KEY }}
          script: |
            set -e
            JAR_FILE=$(ls -t /home/ec2-user/build/libs/*.jar | grep -v plain | head -n 1)
            mv /home/ec2-user/acc360-api.jar /home/ec2-user/acc360-api.jar.bak || true
            mv "$JAR_FILE" /home/ec2-user/acc360-api.jar
            sudo systemctl restart acc360

Now, every push to develop automatically deploys.

Step 6: Add API Gateway for HTTPS

  1. Go to API Gateway → Create API → HTTP API
  2. Create an integration:
  • Type: HTTP
  • URL: http://<EC2_PUBLIC_IP>
  1. Create two routes:

MethodPathANY/{proxy+}ANY/api/{proxy+}

  1. Use the $default stage with auto-deploy enabled.

You now get a free HTTPS endpoint.

Step 7: Checking Logs on EC2

Spring Boot logs

sudo journalctl -u acc360 -f

Service status

sudo systemctl status acc360

Nginx logs

sudo tail -f /var/log/nginx/access.log
sudo tail -f /var/log/nginx/error.log
