Automatic Canny Edge Detection In OpenCV

Canny edge detector was published in 1986 and the input of a Canny operator is simply the output of Sobel. We take an image converted to grayscale and run a gaussian blur. Then we’ve run our Sobel operator in both the X and Y directions. We have calculated the gradient and the orientation of those and that’s enough before canny’s process.

It’s fairly simple but of course, it’s also effective and so to still sees a lot of use. There are other newer edge detectors, and there are certainly a lot of newer filters, that are suing Sobel. Sobel still sees a lot of use. 

Canny takes the output of sobel. Canny works by taking the image from sobel output. Thinning all the edges so they are 1 pixel wide since thick edges don’t really help us. 

Canny works first finding the edges and then use a process called hysteresis thresholding which sees use in other areas. It is essentially a two-level threshold which we will talk about later. The first thing to do for every pixel try to find out if its local maximum that means that is bigger than its neighbours.
