Single Image Reflection Removal Based on GAN With Gradient Constraint

R. Abiko and M. Ikehara, “Single Image Reflection Removal Based on GAN With Gradient Constraint,” in IEEE Access, vol. 7, pp. 148790–148799, 2019.
doi: 10.1109/ACCESS.2019.2947266

A GAN based approach with four different losses including pixel loss, feature loss, adversarial loss and gradient constraint loss is proposed to separate the reflection layer from the image.

The novel is gradient constraint loss which tries to minimize the correlation between the background and reflection layer.

Image Separation


Authors noticed one vital thing in recent approaches that some of the images missed their original colour tone when their reflection is separated because the structure of the background layer still appears in the reflection layer this is what authors assumed.

What authors decide is Independence of the reflection layer and the background layer should be kept so they come up with the new loss which is called gradient constraint loss. 

addition to gradient constraint loss, they defined the following losses as well. feature loss which is responsible for feature preserving when two layers are separated, pixel loss corresponds to pixel loss and adversarial loss which corresponds to how realistic the output images are.


The architecture is made bu combination of a convolutional layer, batch

layer, and bilinear interpolation layer.

Our Generator tries to generate the background image from the original image The Background image B^i can be shown as below with respect to input image I^i and Learnt weights Qg

B^i = G( I^i, Qg)

Reflection layer can be got by subtracting background image from the original image as follow

R^i = I^i - B^i
