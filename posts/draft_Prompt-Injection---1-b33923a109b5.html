Prompt Injection — 1


Most of us use chatgpt, gemini or claude in our daily life. These are LLM models.

What actually we do? We give some input to the LLM and we get the response from LLM.

So, LLM response is based on our input prompt isn’t?

before we jump into concept lets first understand the difference between prompt and instruction

  • Prompt → the message/input given to the LLM
  • Instruction → what you are telling the LLM to do
