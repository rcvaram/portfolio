Disk Structure

We have constant logical circles on disk circle difference space is called as track. Also, We have sectors which are diving the disk into pieces like cake cutting.

Block is nothing but intersection potion of sector and track. so any potion of the block can be addressed using track number and sector number. Typical block size is 512 bytes

In one block, the first address 0 and last address is 511 then each byte has its own address what we called as an offset. each byte can refer in terms of block address and offset.

With track number, sector number and offset we can reach the byte address.

When we spin the disk, we are changing the sector place and when we move the writing header then we are changing the track place. 

The data is brought into memory from disk for processing since the CPU can access data only which is in the main memory. Data structures that we studied, are used in Main memory. The data which is stored in the disk is DBMS.
