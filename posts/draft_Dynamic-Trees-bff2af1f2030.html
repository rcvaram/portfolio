Dynamic Trees

BST

This is a dynamic data structure with the following functions

  • Search
  • Minimum
  • Maximum
  • Insert
  • Delete
  • Predecessor
  • Successor

The time complexity of the above functions is basically the height of the tree. When we have a complete binary tree, the time complexity is O(logn) and the linear tree then we have O(n).

BST is created with nodes. Each node has key and it’s successors and predecessor. Each node has a maximum one parent (except root) and a maximum of two children left and right. always there is a maximum of two paths from one node that’s why we called this a binary tree.

Children are arranged in a manner like the left child is smaller than the current node and the right child is greater than the current node. Because of this arrangement, we can easily search the element with time complexity of tree height. This is an optimized pattern for searching that’s why we add the term search in this kind of data structure name. Finally, A binary tree which has an optimized pattern for search is called a binary search tree.

Binary Search Tree Terms

Root → First node which is in top of the tree, and doesn’t have a parent

Leaf → The node who doesn’t have children and they will be in the bottom

Height of a node → edges on the longest simple downward path from the node to a leaf

Height of a tree → edges on the longest simple downward path from the root to a leaf.

Depth of a node → longest simple path from the root to the node.

In order successor → It is not a direct child it is the left last node in the right subtree from the particular node.

def searchOnBST(node, searchValue):
    nodeValue = node.getValue()
    if nodeValue == searchValue:
       return node
    elif nodeValue<searchValue:
       searchOnBST(node.getRightChild(), searchValue)
    else:
       searchOnBST(node.getLeftChild(), searchValue)

We first check the searching value with current node value and if it is the same we return the node and if the searching value is greater than the current node which means the search value will only be in right subtree so we only search in the right subtree. and if it is less than the current node value then that will be in the left subtree.

def insert(tree, new):
   node = tree.getRoot()
   if node== null:
      tree.setRoot(new)
      return tree
   else:
      while node != null:
          val = node.getValue()
          newVal = new.getValue()
          if newVal<= val:
             node = node.getLeftChild()
          else:
             node = node.getRightChild()
      new.setParent(node)

Deleting a node in BST

Deletion is very important since this understanding can be used to understand self-balancing in the binary tree.

We need to take care of node position when we aimed to delete that node.

  • When the node has no children, we can simply delete the node and make it’s parent’s child( where the node act like a child) to null.
  • when the node has a child, we can simply remove the node and move the node’s child to the node’s parent’s child. Simply we remove the node and give its’ child to that position.
  • when the node has two children. We find the inorder successor, we replace the node with the inorder successor. When the inorder successor has right child, we will make the inorder successor’s right child to inorder succesor’s position

Treaps < Self-Balanced Binary Tree>

Treaps → Tree + Heap

Simply we can say treap is a kind of BST with randomized order of nodes. How can we build this? We use heap property to rearrange the nodes after inserting the node.

When we inserting the node, we insert with BST properties. After the insertion, we use heap property to rearrange it.

BST property → Insertion 
HEAP property → Rearrange the nodes.


How can we use Heap Property?

For heap property, we have an additional attribute in the node which we called as a priority. We arrange the tree in max priority heap manner or min priority heap manner.

class node {
   int value;
   String priority;
   node parent;
   node leftChild;
   node rightChild;
}

Here, the values obey the BST property and priority will obey the heap property.

When the values and priorities are distinct, there is an only one means unique treap with these nodes and the expected height of the treap will be logn.


Insertion in Treap

To insert a node in treap, We will assign a random priority to that node. Based on value, we will insert the node into treap without violating the BST property. (We don’t care about heap property initially)

After inserting, we rearrange the treap based on priority to not violating the heap property. For this, we use rotations.  

Rotations in BST

When we do the right rotation, we focus on the following things.

  • We make the left child to the node position and the node will move to the position of a right child for the left child of it.
  • Now, We may have the right subtree of the old left child node without a position. We move this right subtree to our node left child.

When we do the left rotation, we focus on the following things.

  • We make the right child to the node position and the node will move to the position of a left child for the right child of it.
  • We may have the left subtree of right child of the node without a position. We move to this right subtree to our node right child place.

Rotations are used to maintain the heap property

Red Black Tree

It is a specific type of BST. Red-Black has some property.

  • A node is either Red or Black 
  • The root is black.
  • Null nodes are considered as black
  • If a node is red then it’s children should be black.
  • All paths from the node to leaf should have the same number of black nodes.

When we inserting an element to red-black tree, we need to take care of the above properties. For simplicity, we define some procedures to do the insertion.

Procedures for insertion

  • Parent, grandparent and uncle →
  • when we have the parent is red and uncle is red we change the colours of an uncle, parent and grandparent.
  • When we have the parent is red and uncle is black
  •  → node is left child of the parent and the parent is the right child of grandpa then We rotate the parent in the opposite direction of node. 
  • → node is the right child of the parent and the parent is the right child of grandpa then We rotate the grandpa with the parent in the opposite direction of node. Then you will recolour the parent and grandparent.
