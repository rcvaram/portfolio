Famous Sudoku Line Detection

Line detection is very important in the computer vision area. For line detection, Hough lines and probabilistic Hough lines are algorithms which are implemented in OpenCV. 

How hough lines represent lines? you know that we can represent a straight line with Y =mx+c here m is gradient and c is the y-intercept. Also, we can represent line as p =xcosQ +ysinQ similar to y =mx+x 

y = mx+c
m =tanA
y =tanAx+c
y =sinA/cosA *x +c
cosAy = sinA *x +c cosA
Q =90-A
-y*SinQ = x*CosQ -c *cosQ

p = xCosQ + ysinQ ; p = c * cosQ

So We can represent a line with Q which is the angle formed by the normal of this line to the origin( measured in radius) and p which is the perpendicular distance from the origin

OpenCV reference point is the top left corner, not the bottom left corner. Based on that, P,Q can be marked as below.

So the houghLines function of OpenCV takes input arguments binarized image, P,Q, threshold. the threshold is the minimum value for it to be considered as a line. In our example, we run houglines function with theta accuracy one degree and rho accuracy 1 pixel. The threshold value is key value to detect lines since if it is low you may detect unwanted lines or if it is high you may not detect the needed lines.

import cv2
import numpy as np
img = cv2.imread(image_path, 0)
image = img.copy()
img = cv2.Canny(img, 100,170 ,apertureSize =3)
cv2.HoughLines(img, p, q, threshold)
lines = cv2.Houghlines(img, 1,np.pi/180,240)
for rho, theta in lines[0]:
    a =np.cos(theta)
    b = np.sin(theta)
    x0 = a*rho
    y0 =b*rho
    x1 = int(x0 + 1000 *(-b))
    y1 = int(y0 + 1000 *(a))
    x2 = int(x0 -1000 *(-b))
    y2= int(y0 + 1000 *(a))]
    cv2.line(image, (x1,y1),(x2,y2), (255,0,0),2)

Above for loop is used to iterate each line and convert it to the format which is required by cv.lines function. 1000 is used to make a total offset of 2000 between the starting/ ending points of the lines segments.



probabilistic Hough lines takes only a random subset of points sufficient enough for line detection. However, we specify a minimum vote (pts along the line) of 100 and Min length of 5 pixels and the max gap between lines of 10 pixels
