Completable Future 


Three States

  • Result
  • Reject
  • Pending

Functional Interfaces

  • Supplier<T> → T get() factories
  • Predicate<T> → boolean test(T) filter
  • Function <T, R> → R apply (T) map
  • Consumer <T> → void accept(T) foreach

Promises have two channels. 

  • Data Channel
  • Error Channel 

If things are going well, the flow will be in the data channel and if something went wrong it will be moved to the error channel. and if you recover, then the flow again moves back to the data channel.
