Let's Talk About CNN 



Imagine a simple image classifier using a neural network that takes color images of size 64 x 64 so the input size to our NN would be 64 x 64 x 3 = 12,288. Therefore, our input layer will thus have 12,288 weights while not an insanely large amount, imaging using input images 640 x 480? You’d have 921,600 weights! Add some more hidden layers and you will see how fast this can grow out of control. Leading to very long training times.

So What CNN does….

CNN doesn't actually reduce the weights at the beginning and the input but it does do it. It finds a representation internally in hidden layers to basically take advantage of how images are formed so that e can actually make a neural net much more effective on image data.

This is an overview of CNN. in the first, Convolution where the ReLU activation unit is applied to the convolution here. This convolution applies the cross image to produce values.

3D layers allow us to use convolutions to learn image features. use far fewer weights in our deep network, allowing for significantly faster training.

Convolutions 

Before convolutions, we need to know about image features. Image features are simply interesting areas of an image like edges, colors, patterns, and shapes.

In the old days, we computer scientists had to understand our image and select appropriate features manually such as 

  1. Histogram of gradients 
  2. Colour Histograms
  3. Binarization
  4. And many more

This process was tedious and highly dependent on the original dataset( meaning the feature engineering done for one set of images would not always be appropriate to another image dataset.)

Convolution is a mathematical term to describe the process of combining two functions to produce a third function. This third one is called as a feature Map. Convolution is the action of using a filter or kernel that is applied to the input. In our case, the input is our input image.

Convolutions are executed by sliding the filter, kernel over the input image. This sliding process is a simple matrix multiplication or dot product.

This our input image. 

What are the effects of kernel

Depending on the values on the kernel matrix, we produce different feature maps. Applying our kernel produces scalar outputs as we just saw. Convolving with different kernels produces interesting feature maps that can be used to detect different features. Convolution keeps the spatial relationship between pixels by learning image features over the small segmentation we pass over on the input image.

By tweaking the following parameters to control the size of our feature maps. 

  1. Kernel Size
  2. Depth → The number of filters used. Each filter can learn different features in the presence of different image features like edges, patterns, layouts.
  3. Stride → Step size we take when we slide our kernel to the input image. Stride controls the size of the convolution layer output. Using a larger stride produces less overlap in kernels. Strides are one of the methods we can control the spatial input size.
  4. Zero padding→ We add a border of 0s around our input to get borders into the matrix convolution. Basically this is equivalent of adding a black border around an image. IT allows us to create the same feature map of the input image. 


ReLU Activation Function

The activation layer choice for CNNs

So the convolution is linear and we need to introduce non-linearity into our model. For that, we need to apply an activation function to the output of the convolutional layer. 

Pooling Layer

It is basically subsampling or downsampling. It is a simple process where we reduce the size or dimensionality of the Feature Map. The purpose of this reduction is to reduce the number of parameters needed to train whilst retaining the most important features. 

Three types of pooling are there.

  1. Average → Get the average value out of each kernel to compress the image.
  2. Sum → Get the total value out of each kernel to compress the image.
  3. Max → Gets the maximum value out of each kernel to compress the image.


Typically Pooling is down using 2x2 windows with a stride of 2 and without padding for smaller input images. for larger ones, we can use 3x3. Using the above settings we can reduce the dimensionality of the previous layer by half and thus removing 3/4 of the activations seen in the previous layer.

This makes our model more invariant to small minor transformations or distortions in our input image since we’re now averaging or taking the max output from a small area of our image. 

The Fully Connected Layer

Fully connected means all nodes in one layer are connected to the outputs of the next layer. The FC layer outputs the class probabilities where each layer class is assigned a probability. All probabilities must sum to 1.

The Final activation function is the softmax function which is used in this layer. 

Example:

lets say the output of FC layer was [2,1,1]. applying the softmax squashes these teal value numbers into probabilities that sum to one. 

Training CNNs

CNNs are the NN of choice for image classification. It learns spatial image features but because of the max pooling and multiple filters, it is somewhat scale and distortion invariant.

[Input image → Convolution → ReLU → Pooling → Fully Connected]

Above what really a CNN

Training CNN can be looked below

  1. Random Weight initialization in the convolution kernels
  2. Forward propagates an image through our network ([Input image → Convolution → ReLU → Pooling → Fully Connected])
  3. Calculates the total error
  4. Use the Back Propagation to update our weights via gradient descent
  5. Keep Propagating all images through our network till an Epoch is complete
  6. Keep completing Epochs until our loss and accuracy are satisfactory.


Our Own CNNs

Basic CNNs all follow a simple set of rules and layer sequences. 

[Input image → Convolution → ReLU → Pooling → Fully Connected → output]

Input Layer typically square. this is not necessary but simplifies our design and speeds up our matrix calculations. Input should be divisible by at least 4 which allows for downsampling. Filters are typically smaller like 3x3 or 5x5. Strides typically 1 or 2. Zero paddings is used typically the output Conv layer to be the same size as the input. The pool kernel is typically 2x2. Dropout is a very useful technique to avoid overfitting in CNNs.
