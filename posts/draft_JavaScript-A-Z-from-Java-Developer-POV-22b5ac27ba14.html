JavaScript A-Z from Java Developer POV


Javascript is dynamically typed. This is one of the major difference from Java. 

Java

int age = 5;
String name = "sivaram"
boolean isActive = true;

In javascript we dont need to tell the type when we define the variable. Javascript automatically decides the type.

let age = 5;
let name = "sivaram";
const active = true;

Javascript defines the type at runtime. The below code also run in Javascript without any issues. 

This is a fundamental characteristics in JavaScript. 
let myVal = 6;
myVal = "sivaram";
value = true;

Let vs Const vs Var

let age = 5;
const name = "age";
var country = "germany";
  • Prefer const
  • Use let when you need a reassignment. 
  • Avoid var unless you need to dig into the legacy code.

const

const color = "red";

You can not reassign it. 

color = "blue";

This is produces an error however don’t forget above an important detail.

const square = {
    color: "red"
};

square.color = "blue";

const prevents reassignment of the variable binding. It does not make the immutable.

Let

Use let when variable could change.

let counter = 0;
counter++;
