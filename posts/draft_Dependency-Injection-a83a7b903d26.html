Dependency Injection

We build objects which is depend on other objects
For a real example
A car has tyre, engine, seat and many other things for that, car depend on these things isn’t?
If you think Toyota company they build many different cars with different prize. how they difference between them because of their engine, tyre and other stufs so the car is depends on these things.

In this car, as well toyoto don’t build all things of Car, they can get the tyres from other company, may be the seats fromanther company.

Same way, when we have an object which is depend on other objects.
As software best practice loose coupling is very important one.
Loose coupling means it should depend on other objects will be much lesserthan.

When we are going to code this. we will code like this. 
Class Car{
String name;
Tyre tyre = new TvsTyre();
}
In this moment, we have hardcoded and this is tight coupling. Here the Car is depended on Tyre and the tyre and the car has tight coupling. We want to get rid of this tight coupling
We want to inject the tyre inside the car.
How can we do it? for that we can use services to inject the object.
In our Spring framework,
Spring contaienrs, They will create the objects for u and then inject them in your class. How can we do? We have to do configurations.
XML configurations, Annotations configurations
We can create XML file and the xml file you can mention like when some one ask the tyre you can give this tyre like that. so this is not tight coupling because we can change it in the xml file.
As a developer, I want to work with these xml configurations??
