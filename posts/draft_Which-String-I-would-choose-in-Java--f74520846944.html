Which String I would choose in Java?

I prefer String literal almost in my projects, In some scenaraios StringBuilder or StringBuffer outperform the defualt String class.

We basically need to store the text and java provides three main ways.

  1. String class
  2. StringBuilder class
  3. StringBuffer class

Let’s say i have text like below

Software Engineer with 5+ years of experience designing and
operating distributed systems and Java/Spring Boot microservices 
with hands-on experience developing React-based frontends.

If I need to build above String like

String introduction = "Software Engineer with 5+ years of experience";
String introduction = introduction + "designing and
operating distributed systems and Java/Spring Boot microservices";
String intoduction = introduction + "with hands-on experience developing React-based frontends.";

I mutated the introduction again and again. It evolves…

So in that case, String is not a good option to go with it.

StringBuilder and StringBuffer gives us mutability which does not provided by String.
