Image preprocessing

The above Diagram represents what we have planned to do inside the preprocessing. Cropping, Deskewing, Glare removal, binarization, divide the image into chunks are the steps involved in the image preprocessing.

The images can be taken in different manner like below since the images are taken by the handheld cameras.

So the photos may not be in the correct orientation. we need to do the rotation cropping and resizing. these will be happened in the cropping phase. Using canny edge detection we find the edges of images. We can find the contour which we need to crop since the area of contour is well known.

Images may affected be skewing, we need to do deskewing. Using Hough transform, we can determine the peaks.after that, we can estimate the skew angle with the help of these peaks.

Glare will affect the binarization and segmentation so we need to remove the glare. glare can be removed in different techniques which we explained above.
