Array In C


int a;

a gets some memory allocation. we can assign 10 to a. also we can assign 20 to a but this time 10 will replace by 20 since we are using primitive type we can store only one value in a variable.

Using an Array we can store n number of elements but on the same data type. 

Declaration of Array

int[5] a; // 5 is the size of array


  a        0 1 2 3 4
[2046]    [][][][][]
         2046

a is array variable 5 size of block memory is allocated. We can use the index to process array elements. the starting address of array will be hold by a. An array variable is called the internal pointer variable. It holds the base address of the array.
