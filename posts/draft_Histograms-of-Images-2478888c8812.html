Histograms of Images

Histograms are a great way to visualize individual colour components.

First, we look calHist function which is used to represent the histogram of the image in opencv. It takes five arguments; images, channels, mask, histSize, ranges[,hit[,accumulate]]].

Here, 

1. images — It is the source iamge of type unit8 or flaot32. It should be given in square brackets as list

2. channels — It is also given in square brackets as a list. It is the index of the channel for which we calculate histogram. If the input is a grayscale image, its value is [0].

3. mask — mask image. to find histogram of the full image, It is given as “None”. But if you want to find histogram of a particular region of the image, you have to create a mask image for that and give it as a mask.

4. histSize — this represents our BIN count. Need to be given in square brackets. For full scale, we pass [256]

5. ranges — Range of pixel normally 0–255

histogram = cv2.calcHist([image],[0],None,[256],[0,256])
