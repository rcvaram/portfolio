1. What is Pointer?

A pointer is a variable which stores memory address of another variable instead of the actual value

int x = 3;  
int *px = &x;

Here 3 stored into x and x address could be 1000. in that case px value stores the x address which is 1000. 

pointers allow programs to access the directly access and modify the data stored in the memory address. It’s a widely used way to access the data in embedded systems since these systems are used tiny memory. 

2. What is the difference between * and & ?

& it returns the memory address of the variable. * access the value stored and stored at a address.

int x = 3;
int *p = &x;

&x address of the x variable — 1000.
 p stores this address so p = 1000;
*p access the p memory address which means it sees the value of 1000 = 3

3. Why pointers are used in embedded systems?

Pointers are used since they allow direct memory address. in embedded systems LEDs, sensors, timers, and communication ports are controlled through specific memory address. Pointers are used directy write and read the values from the memory address. 

4. What is call by value?

C uses call by value which means when it passes a value in function instead of original value it passes the copy of the value hence the changes made to the value will not affect the original value.

void change(int x){
 x = 20;
}

int x = 100;

change(x);

printf(x); // still its 100

6. Why is the array name equal to the address of the first element?

In C, name of an array represents the address of the first element.

int a[5];

Here, &a[0] and a are equal. both are refers to address of the first element of the array.

7. Why is a[i] equal to *(a+i)?

Array indexing in C is implemented with pointer arithmetic. 

a points to the first element of the array.

a+i moves the pointer to i th element

*(a+i) access the ith element address.

So

a[i] = *(&a[0]+i) = *(a+i)
