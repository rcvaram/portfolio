Retry In Spring 

When you are dealing with external API calls / external dependencies, you might not get the desired response because of time/memory inconsistent at that time, If you fail that scenario, you have to try again if it is possible for some times. 

For that, we can do like below with while loop

boolean getResponse(){}
while(times <4){
boolean status = getResponse();
if(status){
break;
}
else{times =times+1;}
}

This is a very simple code that can execute the getResponse method to get success status not more than three times.

If we try and all three times, we failed we need to do some recovery steps. In the above code, we can do like below.

boolean getResponse(){}
void recovery(){}
while(times <4){
boolean status = getResponse();
if(status){
break;
}
else if(times ==3){
recvoery();
}
else{times =times+1;}
}
