Image Segmentation with Contours

Segmentation is a process that partitioning images into different regions. We need to understand contours if we go for image segmentation. 

Contours

contours are continuous lines or curves that bound or cover the full boundary of an object in an image.

These contours are very important in object detection and shape analysis.

img = cv2.imread(imagep_path)
image = img.copy()
gray_img - cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
edges = cv2.Canny(gray_img, 30,200)
contours, hierarchy = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHANI_APPROX_NONE)
print("Number of Contours found - {}".format(len(contours)))
cv2.drawContours(image, contours, -1, (0,255,0),3)

First, we take the edges of the image using the canny edge detector.

Finding canny edges isn’t necessary because we can pass the grayscale image to find contours but It will reduce the noises.

findContours is the function that we need to discuss here. This function takes three input arguments. The first argument is an image that should be a grayscale image. The second is a retrieval mode and the third one is the approximation mode. When we apply the findContours method the original image will be affected. in our case “edges” image will be affected. The best practice is to take a copy of the image before processing the findContours method.

OpenCV stores the contours in a list of the list. Each list represents a different contour. within the list, all the coordinates of that contour are added to that list. We can store these coordinates differently. How can we store that? The approximation mode comes to play. Using cv2.CHAIN_APPROX_NONE stores all the boundary points. But we don’t necessarily need all the boundary points. If the points form a straight line we only need the start and ending points of that line. Using cv2.CHAIN_APPROX_SIMPLE instead only provides these start and endpoints of bounding contours, thus resulting in much more efficient storage of contour information.

We have discussed the approximation mode above. what is retrieval mode? Retrieval mode essentially defines the hierarchy of the contour as so hierarchy being like do you want sub contours or external contours or all contours.

There are four types in retrieval mode in OpenCV.

  1. cv2.RETR_LIST → Retrieve all contours
  2. cv2.RETR_EXTERNAL → Retrieves external or outer contours only
  3. cv2.RETR_COMP → Retrieves all in a 2-level hierarchy
  4. cv2.RETR_TREE → Retrieves all in the full hierarchy

Hierarchy is stored in the following format [next, previous, First child, parent]

We discussed all the things about the findContours method as I think.

The output of this function returns contours and hierarchy.

Sorting Contours

sorting contours is good when we are doing image processing.

We can ignore contours with the help of the area. Eliminating small contours will be good since those contours may be noise.

Sorting Contours by Area

We need to know the area of contours to sort out them.

Following function is used to get the area of the contour

def get_contour_area(contours):
    contour_areas =[]
    for cnt in contours:
        area = cv2.contourArea(cnt)
         contour_areas.append(area)
   return contour_areas
print(get_contour_area(contours))

Here, cv2.contourArea calculates the area of the contour. Your terminal will show the unsorted area list.

We can sort contours large to small using below line

sorted_contours = sorted(contours, key = contourArea, reverse =True)
print(get_contour_area(sorted_contours))

Now, you can see the sorted contours by area.

The first contour will be the largest contour in the image.

Cropping Contour

It is very easy in OpenCV. cv2.boundingRect is the function that is used to crop the contour in rectangle shape. It will give the starting point of coordinate x,y then the width and the height.

x,y,w,h = cv2.boundingRect(contour)
cropped_contour = image[y:y+h,x:x+w]

We can approximate the contours to the shape using the approxPolyDP function of OpenCV. It takes arguments such as contour, approximation accuracy, closed.

contour → Individual contour we wish to approximate.

Approximation Accuracy → Important parameter is determining of the approximation. Small values give precise-approximation, large values give more generic approximation. A good rule of thumb is less than 5% of the contour perimeter. 

Closed → A boolean value that states whether the approximate contour should be closed or not.

for c in contours:
    accuracy = 0.05*cv2.arcLength(c,True)
    approx = cv2.approxPolyDP(c, accuracy, True)
    cv2.drawContours(image, [approx],0,(0,255,0),2)
