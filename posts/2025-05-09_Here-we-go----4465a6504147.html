Here we go...

Clean Java code can be achieved using:

1. Decorator patterns (for layered behavior)

2. Filters/interceptors (e.g., in Spring MVC/WebFlux)

3. Functional composition (with Java 8+)

4. Dependency injection of behaviors (for better testability)

AOP is one tool — not the only tool. Use it where it fits. Don’t force it where simplicity suffices.
