Why Go

Go is developed by Google. Ken Thomson, Rob Pike and Robert Griesemer invented the Go. When the program is running the main requirement is performance. For better performance, programmers are going with C language but C language syntax is difficult. Here comes GO super fast and very native syntax. Many of the programming languages work on single-core but we have multiple core support in hardware. The GO is written to take advantage of multicore natively and well so the Go is doing concurrency easily or managing the concurrency very easily. It is compiled language so everything should go to binary after the go build process so there is no virtual machines or interpreters. It has a garbage collector so it will manage the memory. It has clean syntax and powerful standard library. It can portable. The beautiful thing is Go is an Open-source project.

Go is used by Google, Dropbox, Docker Firebox, IBM, Facebook, Uber more…

Go can be used to write web apps, scripts, system administration, image processing, load balancers, servers, crypto OS as well. 

Libraries of Go is very large when you want some packages you can go and get it and import your code.
