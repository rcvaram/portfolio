Jenkins — Short Notes

What?

Jenkins is an automation platform that allows you to build, test, and deploy the software through pipelines. In addition to that, Jenkins is used to automate any tasks such as Python scripts and Bash tasks.

Jenkins provides a WEB GUI where you can create jobs and all the functionalities you want such as source control management, free and enforced build action, and also build triggers. 

How?

Jenkins Infrastructure 

Master Server → Controls pipelines and, schedules builds to agents. 
Agents → Runs the build in their workspace
Ex → The developer commits some code to a git repository. The master server becomes aware of this commit, triggers the appropriate pipeline, and distributes the build to one of the agents to run. Master Server selects appropriate agents based on labels which is something that you can configure through the Jenkins UI the agent runs the build which is usually just a bunch of Linux commands to build test and distribute your code.

Agent Types

Permanent Agents

  • Dedicated Servers for running Jobs. 

Cloud Agents

  • Ephemeral / Dynamic Agents spun up on demand.

Build Types

Freestyle Build

  • The simplest method to create a build
  • Shell scripting

Pipelines

  • Use the Groovy Syntax
  • Use stages to break down components of builds
